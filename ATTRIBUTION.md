## Speech synthesis (SAM)

- **SAM (Software Automatic Mouth):** written by Mark Barton and published in 1982 by Don't Ask Software (now SoftVoice, Inc.).
- **C port:** a reverse-engineered version by Sebastian Macke: <https://github.com/s-macke/SAM>
- **Python port (`samtts`):** an unofficial port by jacklinquan: <https://github.com/jacklinquan/samtts>

SAM is commercial software whose original authors could not be reached, and
its copyright status is unclear. This repository does **not** include SAM's
code or any audio generated by it. Users install `samtts` themselves with pip
and are responsible for checking its license terms.
